# Portal de Seguimiento Docente — EEGG Lima Norte — 2026-II

Primera versión visual del portal institucional para docentes y coordinación. Usa datos de demostración y no incluye autenticación real ni conexión a Supabase.

## Ejecución local

```bash
pnpm install
pnpm dev
```

Abre la URL local que aparece en la terminal. Los campos de acceso contienen credenciales de demostración. Puedes elegir **Docente** o **Coordinación** antes de ingresar.
